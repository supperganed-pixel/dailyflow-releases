# DailyFlow downloads

DailyFlow is an Android app for tasks, notes, follow-ups, and private files.

## Latest preview: 1.0.2

The Android APK is being built on Expo. [Open the latest build page](https://expo.dev/accounts/newflow1/projects/dailyflow/builds/7a4ea22a-c186-4471-bde2-907329493a0d) to see its status and download it when the build finishes.

This preview adds an animated sign-in and signup screen, a four-step getting-started guide for new accounts, and a guide link in More and Settings. Firebase email authentication and private Supabase-backed data remain in the app.

Only install APKs from this repository or the linked Expo build page. Android may ask you to approve installation from your browser or file manager.

[View the public source code](https://github.com/supperganed-pixel/Dailyflow-app).
