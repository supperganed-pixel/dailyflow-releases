# DailyFlow downloads

DailyFlow is an Android app for tasks, notes, follow-ups, private files, and a focused daily plan.

## Latest preview: 1.0.4

The signed Android APK is being built on Expo. [Open the DailyFlow 1.0.4 build page](https://expo.dev/accounts/newflow1/projects/dailyflow/builds/da347e13-df7c-4988-8f3d-e1d4bfef93f2) to see its status and download it when the build finishes.

### What’s new

- Swipe task actions with undo and animated completion
- Expandable task cards and animated Focus progress
- Light and dark themes, four accent colors, custom greeting and dashboard layouts
- A private profile with display name, avatar and bio
- A dedicated profile button in the top-right
- Android notification-bar reminders with sound and an in-app notification test
- Today dashboard, Top 3 Focus, dependencies, follow-up history and end-of-day review

Android reminders are scheduled on the device and can appear while DailyFlow is closed after reminders are enabled and scheduled. This preview does not send remote social-style push messages from a server.

Only install APKs from this repository or the linked Expo build page. Android may ask you to approve installation from your browser or file manager.

[View the public source code](https://github.com/supperganed-pixel/Dailyflow-app).
