# DailyFlow downloads

DailyFlow is an Android app for tasks, notes, follow-ups, private files, and a focused daily plan.

## Latest preview: 1.0.5

The corrected signed APK is building on Expo. [Open the DailyFlow 1.0.5 build page](https://expo.dev/accounts/newflow1/projects/dailyflow/builds/69d8a238-29e3-47e5-8fee-e2892ad5e60a) to follow the build and download it when ready.

### Corrections in 1.0.5

- Removed conflicting Android version metadata
- Strengthened GitHub release-response validation
- Preserved test and other scheduled notifications when task reminders refresh
- Includes all profile, appearance, task interaction, Focus and notification features from 1.0.4

Android reminders are scheduled on the device and can appear while DailyFlow is closed after reminders are enabled and scheduled. Remote social-style push messages are not included yet.

Only install APKs from this repository or the linked Expo build page. Android may ask you to approve installation from your browser or file manager.

[View the public source code](https://github.com/supperganed-pixel/Dailyflow-app).
