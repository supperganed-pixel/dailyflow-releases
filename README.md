# DailyFlow downloads

DailyFlow is an Android app for tasks, notes, follow-ups, and private files.

## Latest preview: 1.0.3

The Android APK is being built on Expo. [Open the 1.0.3 build page](https://expo.dev/accounts/newflow1/projects/dailyflow/builds/02abf506-80ef-4bba-b219-d8070c35760a) to see its status and download it when the build finishes.

This preview adds a Today dashboard, Top 3 Daily Focus, explainable priority suggestions, follow-up and waiting history, task dependencies with blocked status, and an end-of-day review. It also includes the animated sign-in and signup screen and four-step guide for new accounts. Firebase email authentication and private Supabase-backed data remain in the app.

Only install APKs from this repository or the linked Expo build page. Android may ask you to approve installation from your browser or file manager.

[View the public source code](https://github.com/supperganed-pixel/Dailyflow-app).
